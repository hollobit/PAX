광진구 실무자가 만든 LexDiff를 경기도의회가 재사용해 구축한 지능형 법령정보 서비스. 법제처 데이터 기반으로 위임법령 3단 비교·신구법 대조·판례 통합 검색·전국 조례 벤치마킹·위임 미비 탐지와 일상 언어 AI 법률 질의응답을 제공한다. 화면 하단에 원작자 권한을 표기하고 API 비용 보호를 위해 수도권 접속 제한을 둔, 개인 개발 도구의 타 기관 재사용 계보가 명시된 사례다.
