군집 지능 시뮬레이션 엔진 MiroFish의 한글 번역판을 포크해 공공 정책 시뮬레이션용으로 손본 개인 수정판이 공유됐다. Zep Cloud 의존을 로컬 SQLite로 바꾸고 Codex CLI 실행에 Claude CLI 폴백과 로컬 LLM 경로를 더했으며, 레딧·트위터에 더해 Threads 성격의 시뮬레이션 플랫폼과 경량·풀 시뮬레이션 모드를 나눴다. 실행 로그 기반 근거 집계와 인용·수치 검증, 정책 쇼케이스 문서를 붙여 대규모 페르소나 노드로 이벤트 타임라인을 예측하는 정책 검토 도구로 쓰는 시도다.
