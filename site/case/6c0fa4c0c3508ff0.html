행사 후 수백 장의 사진에서 등록해 둔 인물이 찍힌 것만 골라 인물별 폴더로 자동 정리하는 도구가 공공 깃랩에 공개됐다. 외부 AI API 대신 PC에서 직접 도는 얼굴 인식 CNN을 써서 최초 1회 모델 다운로드 후에는 폐쇄망에서도 동작하고 사진이 외부로 전송되지 않는다. CPU 전용에 1,000장 약 40분이라는 처리 시간까지 정직하게 고지하며, 얼굴 정보를 다루는 만큼 비상업 라이선스 동의 절차를 내장했다.
