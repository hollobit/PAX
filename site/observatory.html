모든 지표는 오픈채팅·Threads 자기선택 표본에 기반하며 전국 공공부문 전체를 대표하지 않습니다.

분기 지수

분기 말 데이터 버전은 snapshots/에 고정됩니다. 세 분기가 쌓이면 추이 차트가 이 자리에 표시됩니다.

커뮤니티 활력

사례를 만들어내는 생태계 자체의 활동량 — 오픈채팅 대화, 오픈톡방 가입자, Threads 게시물의 관측치입니다.

오픈톡 가입자 일별 추이

날짜입장퇴장순증누적

누적은 최신 실측 가입자 수를 기준점으로 입장·퇴장 기록을 역산한 값입니다 — 기록 유실 시 과거 구간에 오차가 있을 수 있습니다.

카카오 수치는 수집 아카이브 기반 관측치로 수집 공백 구간은 과소 집계될 수 있으며, Threads는 태그 검색으로 관측된 누적 게시물 수(전체 게시물 수 아님)입니다.

공공데이터 AI 접근성 매트릭스

고가치 공공데이터 도메인별로 커뮤니티·공식 MCP가 존재하는지의 관측 — 풀뿌리 MCP는 "AI가 쓰고 싶은 데이터"의 수요 순위표입니다.

데이터 도메인MCP 관측사례

데이터를 쓰다 결함(API 오류·문서 불일치·형식 문제)을 발견하셨나요? 결함 리포트로 알려주시면 기관별 분기 리포트로 환류합니다. 해결 실적이 확인된 기관은 우선 표시합니다.

모델 현황 — 무엇으로 돌아가는가

사례가 런타임에 어떤 AI 모델에 의존하는지의 실측입니다. 판정은 저장소 README·설정 파일의 명시 근거 기준이며, 개발에만 AI를 쓴 경우(바이브 코딩)는 모델 의존으로 세지 않습니다.

모델 의존 분포

분류건수구체 모델 확인비중의미

확인된 구체 모델

분류별 소계(사례 수)는 위 분포 표의 건수와 정확히 일치합니다. 한 사례가 여러 모델을 쓰면 같은 분류 안의 여러 패밀리에 나타날 수 있어 패밀리 건수의 합은 소계보다 클 수 있습니다. 건수를 누르면 해당 사례가 펼쳐집니다.

분류 · 모델 패밀리사용 사례국산

국산 모델 채택 사례

    모델 중립(BYO)은 MCP 서버처럼 자체 모델 호출 없이 이용자의 클라이언트 모델 위에서 구동되는 사례입니다 — 국산 클라이언트·모델이 확산되면 코드 수정 없이 이식되는 층으로, 국산 전환의 실질 관건이 모델이 아니라 클라이언트 생태계임을 보여줍니다.
