# PAX 공공AX 사례 아카이브

Threads의 `공공AX` 태그와 카카오톡 오픈채팅 "공공AX 네트워크"에서 공공부문 AI
전환(AX, AI Transformation) 사례를 12시간마다 수집하고, AI가 선별·요약한 뒤 공개하는
정적 아카이브입니다.

## 사이트 URL

https://hollobit.github.io/PAX/

## 데이터 갱신

12시간마다(하루 2회) 자동으로 수집·갱신됩니다. 현재 Threads 수집은 가동 중이며, 카카오톡
오픈채팅 수집은 준비 중입니다.

## 익명화 정책

- **공개 정보**: AI가 원문을 재작성한 요약만 공개합니다. 원문을 그대로 옮기지
  않습니다.
- **작성자 익명화**: 제보자·작성자의 닉네임 등 개인 정보는 공개하지 않습니다.
- **원문 비공개**: 카카오톡 오픈채팅 원문은 공개하지 않습니다.
- **Threads**: 공개된 원문 게시물의 링크를 함께 제공합니다.

## 파이프라인 구조

수집(원문 읽기)과 선별·요약(실제 공공AX 사례인지 판단하고 재작성하는 것)은 AI가
판단하고, 검증·중복 제거·병합·게시(스키마 검사, 익명화 검사, `data/cases.json`
append-only 갱신)는 결정적 스크립트(`scripts/pax/`)가 수행합니다. AI 판단은
매번 달라질 수 있지만, 공개 데이터에 반영되기 전 마지막 관문은 항상 같은
스크립트가 통과시킵니다.
