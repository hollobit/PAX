# PAX 공공AX 사례 아카이브

공공행정 분야의 웹 접근성(AX) 개선 사례를 수집·분석하는 오픈 소스 아카이브입니다.

## 사이트 URL

GitHub Pages로 자동 배포되며, `https://[깃허브아이디].github.io/PAX/` 형식의 URL에서 접근 가능합니다.

## 데이터 갱신 주기

매일 1회 자동 수집합니다. 오픈채팅방과 기타 공공 소스에서 새로운 사례를 수집하여 데이터베이스를 지속적으로 업데이트합니다.

## 익명화 정책

- **공개 정보**: 사례의 기관명, 날짜, 일반적인 개선 내용만 공개
- **작성자 익명화**: 사례 제보자, 담당자 등의 개인 정보는 전혀 공개하지 않음
- **원문 비공개**: 오픈채팅 원문, 개인 메시지, 민감한 세부정보는 공개하지 않음

## 로컬 테스트

```bash
PYTHONPATH=scripts python3 -m pytest tests/
```

데이터 수집, 변환, 사이트 생성의 각 단계를 테스트합니다.
